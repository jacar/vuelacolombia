# Vuela Colombia | Cazador de Vuelos Baratos Nacionales

Plataforma inteligente de monitoreo continuo, radar en vivo y alertas automáticas de tarifas aéreas por debajo de **$200.000 COP** en Colombia (Avianca, LATAM Airlines Colombia, Wingo, Clic Air y Satena).

---

## 🚀 Características Principales

- **Radar de Precios en Vivo:** Escaneo automático cada 15 segundos de rutas nacionales.
- **Alertas Sonoras y Visuales:** Notificación inmediata al detectar gangas y tarifas rojas.
- **Soporte Multitramo:** Búsqueda flexible de vuelos solo ida, ida y vuelta o múltiples ciudades.
- **Simulador de Vuelos:** Animaciones interactivas de trayectos aéreos.
- **Gráficos de Tendencias:** Histórico y volatilidad de precios a 30 días.
- **Enlaces de Compra Directos:** Redirección oficial a aerolíneas y plataformas de reserva.

---

## 🛠️ Instalación y Uso Local

### Prerrequisitos
- Node.js (v18 o superior)
- npm

### 1. Instalar dependencias
```bash
npm install
```

### 2. Configuración de entorno
Crea un archivo `.env` basado en `.env.example`:
```bash
PORT=3000
```

### 3. Iniciar en modo desarrollo
```bash
npm run dev
```
La aplicación estará disponible en `http://localhost:3000`.

### 4. Compilar para producción
```bash
npm run build
npm start
```
